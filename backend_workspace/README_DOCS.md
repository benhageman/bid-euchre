## 🔗 Key Concepts Quick Reference

### Game Concepts
- **Bid**: Amount of tricks + trump type
- **Trump**: How cards are ranked (high, low, suit)
- **Bower**: Special jack of same color as trump
- **Trick**: 4 cards played (one per player)
- **Team**: Players 0&2 vs Players 1&3

### Technical Concepts
- **Socket.IO**: WebSocket library for real-time communication
- **Redux**: Client-side state management
- **NestJS**: Backend framework
- **Monorepo**: Multiple packages in one repo
- **ValidationService**: Server-side input validation

### Features
- **Real-time multiplayer**: 4 players, instant updates
- **Reconnection**: Auto-rejoin on disconnect
- **AI bots**: Computer opponents
- **Input validation**: All moves checked server-side
- **Connection indicator**: Shows network status
